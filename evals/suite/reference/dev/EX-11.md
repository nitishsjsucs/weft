# EX-11: What the travel and mileage claims add up to

A read-only chat question in the default variant (fix group read-figures, the class "a figure no tool result holds").
The answer is two category sums over every status: the three travel claims (exp_0001, exp_0010 and exp_0014) add up
to $602.88, and the two mileage claims (exp_0006 and exp_0012) come to $155.04. Before the fix no tool returned
either sum, the model had to add amounts, and the grounding guard refused the sums it wrote (money totals come from
tools, never from the answer's arithmetic). Solvable: one `expenses.list` call with totals_by category returns
`by_category`, whose travel entry is $602.88 and whose mileage entry is $155.04; two calls filtered by category return
the same figures as their `totals`. The run files no proposal and writes nothing, and every figure in the reply is
grounded in a tool result of the run.
