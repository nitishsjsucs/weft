# MM-03: Notice run follows the escalation procedure

The NY DTF NYS-45 missing filing notice starts rt_agency_notice in a world whose memory holds the procedure
knowledge/procedures/notice-escalation.md: never claim the filing was made, escalate with `notices.escalate` naming the
form and period, and cite the procedure. The run escalates (executed, R1 with no approval, or proposed), proposes no
rate change, executes no `notices.send_response`, cites the procedure in its summary and commits nothing to memory.
Solvable once the notice routine runs the agent for this kind: recall reaches the procedure by "notice" and "missing
filing", and `memory.search` finds it by name. Today the rt_agency_notice precheck skips every notice that is not a
rate change, so no agent run starts and the task fails on the end state; that is the finding, not an eval bug.
