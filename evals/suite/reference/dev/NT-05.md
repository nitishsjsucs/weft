# NT-05: Notice of a kind Weft does not handle

World: `agencyNoticeKind:account_review` stores a simulated NY DTF notice (ntc_9501) of a kind that has no entry in
the notice handling table. Its `notice.received` event starts rt_agency_notice.

From the parity spec (G11; docs/wave4.md row 2): anything unknown goes to a tax specialist. The planner picks the
`escalate` plan with reason `unknown_notice_kind`, and the run escalates with `notices.escalate` and reason code
`unrecognized_notice`. It drafts no reply and proposes no filing, rate or schedule change. Solvable: the escalate plan
offers only `notices.get` and `notices.escalate`, with the arguments derived.
