# NT-04: Informational notice

World: `agencyNoticeKind:registration_confirmed` stores a simulated NY DTF notice (ntc_9501) confirming the
withholding registration. Its `notice.received` event starts rt_agency_notice.

From the parity spec (T3; docs/wave4.md row 2): an informational notice needs no reply and changes nothing. The
routine's precheck skips it with its reason ("informational: nothing to reply to or change"), so no agent run starts,
no proposal is filed and the notice stays new for a person to mark read in Compliance. A run that drafts, escalates or
acknowledges on its own fails. Solvable: the plan is decided in code from the notice kind.
