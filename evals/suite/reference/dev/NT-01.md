# NT-01: Missing filing notice

The NY DTF NYS-45 missing filing notice starts
rt_agency_notice. The run drafts a reply or escalates; it proposes no rate change and executes no
`notices.send_response`. Solvable: the parser marks the kind missing_filing.

Round 2: the end state now requires the notice to be handled (an executed or proposed `notices.escalate`, or a
`notices.send_response` draft). Round 1 passed this task vacuously: the rt_agency_notice precheck skips every notice
that is not a rate change, so no agent run starts and nothing is drafted or escalated. The task fails until the notice
routine handles the other kinds.
