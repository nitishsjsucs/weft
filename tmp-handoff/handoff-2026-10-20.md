### 4.1 Weft waves 1 to 4 (2026-10-15 to 2026-10-18)

**Waves 1 and 2: the product**

**The agent harness**
- **Who acts:** the executor is the only writer. Consequential tools return proposals, with risk classes R0 to R4.
- **Approval:** re-checks the stored arguments with compare-and-set, so it executes once.
- **Audit:** a hash-chained, append-only action log with Undo.
- **Safety:**
  - taint: untrusted input means the run can only propose;
  - grounding: every number a person reads must appear in a tool result;
  - a vault (AES-256-GCM);
  - budgets and a spend ledger.
- **Memory:** git-backed Markdown.
- **Routines:** run deterministic prechecks.
- **Privacy:** a manager reads full records only for direct reports.
- **Sandbox:** QuickJS, opt-in.
- **Tracing:** Phoenix with OpenInference spans.

**Wave 4: evals and fixes**
- Held-out pass rate on `gpt-5.6-luna` went from 82.9% to 85.4% over two harness rounds, with 0 unsafe actions.
- A fresh held-out split passed 36 and 34 of 41.
- `gpt-5.6-terra` did not beat Luna, at about 10x the cost.

### 4.3 Cloudflare design (2026-10-20)

**The probe** measured the free plan on the account (section 8).

**Research** covered about 45 Cloudflare products against Cloudflare's own docs.

**The seam map** found every Node-only dependency:
- `node:fs` in 35 files;
- `git` run as a subprocess for memory;
- async libsql transactions.

**The judge panel** compared three designs: fidelity-first, Cloudflare-native-first and free-plan-risk-first. Two judges scored them. The synthesis fixed a fatal transaction-facade flaw that one judge reproduced in Miniflare.

**The result:**
- **Front Worker `weft`:** sessions, Turnstile, rate limits, header stripping and an HMAC context header.
- **Private Worker `weft-core`:**
  - one SQLite Durable Object per demo company: a read-only showcase, a pool of leased visitor slots and `slot-smoke`;
  - `LobbyDO` and `SpendDO`;
  - `ReseedWorkflow`, cron, queues and `HostedExtras`.
- **The Next app:** a static export served as Workers static assets.
- **Products used:**
  - compute and state: DO SQLite, alarms, hibernatable WebSockets, Workflows, Queues, KV, D1, R2, Cron, Workers Logs and traces, Secrets Store;
  - AI: Workers AI (the `gpt-oss-120b` switch, OCR with `mistral-small-3.1`, whisper dictation, bge embeddings), AI Gateway in front of every model call, Vectorize, AI Search Help;
  - documents and media: Browser Rendering for PDFs, Images;
  - abuse protection: Turnstile, Rate Limiting;
  - a remote MCP endpoint.
- **Left out, with sources in design section 7.2:**
  - Workers Paid only: Containers, Pipelines, Sandbox SDK, Dynamic Workers;
  - Email Routing: no custom domain;
  - Access: public by decision;
  - the Agents SDK base class: it duplicates the harness.

## 8. Measured free-plan facts (probe, 2026-10-20)

**CPU and size limits**
- **Worker requests:** up to 870 ms CPU succeeded; killed at about 1.8 s (error 1102).
- **Workflow steps:** killed at 2.05 s, so steps only RPC into a DO.
- **Durable Objects:** **30 s CPU per invocation**, fetch and alarm, on Free. Heavy work runs in DOs.
- **Bundle size:** no 3 MB limit anymore (a 10 MB Worker deployed). The docs say 64 MB uncompressed.

**Per-request and daily limits**
- At most 50 external fetches per invocation.
- 100,000 DO rows written per day, shared with the account's other Workers.
- 10,000 Workers AI neurons per day.
- Browser Rendering: about 1 new browser per 20 s.
- The Rate Limiting binding is loose across requests.

**Product availability**
- **Works:** static assets, KV, D1, R2 (usage-metered, so keep the lifecycle rules), Queues, Workflows, DO SQLite (`transactionSync` rollback verified), Vectorize (about 1 to 3 minutes before upserts are queryable), Workers AI, AI Gateway (logs and cache), AI Search, Browser Rendering, Turnstile (widget creation by API accepts workers.dev), Cron (1 of 5 used before Weft), Workers Logs, Secrets Store (one store), Hyperdrive.
- **Paid only:** Containers and Pipelines.
- **Needs a dashboard opt-in:** Analytics Engine (error 10089).
- **Notes:**
  - Qwen3 on Workers AI needs `/no_think`.
